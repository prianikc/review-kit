# Заметки

1. Сделать маленький скилл для коммитов (`/commit`): скилл смотрит на проделанную работу, придумывает
   сообщение для git-коммита и коммитит. Если после команды есть текст — взять его за основу и доработать
   по проделанной работе.
2. Сделать скилл `/push`: пушит текущую ветку и выдаёт ссылку на создание PR.
3. Сделать скилл `/merge` — маленький, по типу `/commit` и `/push` (что именно мержит — уточнить).
4. Сделать скилл `/gsync`: синхронизируется с git — перематывает `main` на последнюю версию, обновляет
   текущую ветку и в целом проверяет, что все ветки актуальные.
