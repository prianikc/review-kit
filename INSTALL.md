# Установка review-kit

Нужен Claude Code 2.1.296 или новее (`claude --version`), Python 3.10 или новее и git.
Версия пакета — в файле `VERSION` архива; ниже `<версия>` — она, например `2.1.3`.

1. Распакуйте архив `review-kit-<версия>.zip` в любую папку вне проекта, например `~/review-kit-<версия>`.
2. В корне проекта запустите Claude с плагином из архива:
   `claude --plugin-dir ~/review-kit-<версия>`
3. Выполните `/review-setup`. Сначала можно посмотреть план без изменений: «/review-setup — только план (--dry-run)».
   Установщик покажет, что удалит из версии 1.17 (если она стоит), и спросит, где держать плагин (вне git или в репозитории).
   Настройки Forgejo из 1.17 переносятся сами.
4. После установки выйдите из Claude и запустите его **без** `--plugin-dir` — иначе в сессии будут две копии плагина.
5. Снова выполните `/review-setup`: он проверит, что мод загрузился, удалит 1.17 и поставит правила review-kit.
6. Откройте новую сессию — правила загрузятся. Проверка: `/pr` показывает PR, по которым есть дело.

Прерванная установка продолжается с места сбоя: просто снова `/review-setup`.

Удаление: «удали review-kit» — установщик спросит подтверждение.

Параллельные ревью (необязательно, нужна Orca): «открой ревью 156, 157 во вкладках» — скилл `pr-tab` создаёт на
каждый PR git worktree в `.claude/worktrees/`, копирует туда локальный слой (`.claude/skills`, `.agents/skills`, все `*.local.*`),
подключает память проекта и открывает в текущем проекте Orca вкладку терминала с `/pr-review N`. Без Orca он печатает
команду для ручного запуска. Чтобы вкладка открывалась без запроса разрешения, добавьте в `.claude/settings.local.json`
правило `Bash(bash .claude/skills/review-kit/tools/open-pr-tab:*)`. Слой задаёт `tabLayer` в `.claude/review-kit.local.json` (glob-шаблоны). «убери вкладку 156» удаляет worktree; законченные worktree вместе с ненужными ветками предлагает убрать `/pr cleanup`.
